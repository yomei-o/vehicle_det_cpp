車両検出デモ

首都高のライブカメラから自動で作った教師データで学習した、小さい車両検出器（yolov8n、1 クラス）です。C++ を WebAssembly にしたもので、ブラウザの中だけで動きます。

このモデルについて

教師は COCO 学習済みの yolo11x（car / motorcycle / bus / truck を 1 クラスにまとめた）。首都高 5 か所のライブ映像 0.5 秒おき 923 枚に教師で枠を付け、yolov8n を学習しました。検証用（各録画の最後の 2 割）で、教師の枠に対して mAP50 0.89・mAP50-95 0.77 です。

C++（このページと同じコード）と Python（onnxruntime）の検出は、枠の差が中央値 0.05px で一致します。
